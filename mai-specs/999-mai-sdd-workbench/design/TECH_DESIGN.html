结构读取模块

原生页面与现有文件能力

侧栏与主区域由 DSH 拥有，插件只注册自己的入口和页面。无需修改 Agent 循环。

明确目标，读取真实内容

  1. 选择会话对应的工作区，列出标准 Feature。
  2. 选择固定文档路径，按 Host 上限读取一页。
  3. 未到文件末尾时允许继续加载；版本变化时要求刷新。
  4. 切换或关闭页面取消旧请求，避免正文串到另一需求。

文档原始 HTML 不执行，图片不自动加载；本地链接不触发任意文件读取。访问权限由 DSH 管理。

小范围模块

+ plugins/mai-sdd-workbench/src/client.jsx
+ plugins/mai-sdd-workbench/src/model.js
+ plugins/mai-sdd-workbench/src/views.jsx
+ plugins/mai-sdd-workbench/src/markdown.js
+ plugins/mai-sdd-workbench/cordis.patch.yml

client 注册与清理，model 约束路径和分页，views 持有页面交互，markdown 负责安全元素。页面离开不留后台轮询；插件禁用时清理入口和当前面板。
