# my-ai-infra SDD 工作台：产品规格

> Profile：standard；模板：`mai-specs/_templates/PRD.tmpl.md`（按本次范围裁剪）；状态：实施依据；日期：2026-11-17。

[返回需求简报](../BRIEF.md)

## 1. 背景与目标

课程作业要求开发可加载的 DSH 插件，并留下与最终代码一致的 SDD 过程。用户希望逐步完成并理解每一步。当前痛点是在聊天与磁盘目录之间切换才能找到 Feature 的需求、设计和评审文件。本次在 DSH 内提供只读工作台，以真实文件帮助用户核对开发过程。

依据：[课程与作业摘要](../context/_INDEX.md)。作业允许从工作台中选一个小能力；本版选择 Feature 导航、Markdown 阅读与手动刷新。

## 2. 用户与流程

用户已在 DSH 中创建属于目标工作区的会话。用户打开侧栏“SDD 工作台”，选择一个会话对应的工作区，选择 Feature，再选择文档；在外部修改文件后点击刷新，最后可返回对话。工作台的工作区选择不改变当前聊天会话。

## 3. 功能需求

| 编号 | 触发 | 预期行为 |
|---|---|---|
| FR-01 | 点击 DSH 侧栏入口 | 在原生主区域打开工作台，提供返回对话按钮 |
| FR-02 | 选择工作区 | 从该会话的 `mai-specs` 列出 `NNN-slug` 目录；展示从 BRIEF 读取的标题与 Phase，未知值明确为未标注 |
| FR-03 | 选择 Feature 和文档 | 查看 BRIEF、PRD、技术设计、设计评审、代码评审、测试计划；标题、列表、代码块和表格可读 |
| FR-04 | 点击刷新 | 重新查询 Feature 列表及当前文档，不依赖浏览器整页重载 |
| FR-05 | 无会话、无目录、无 Feature、缺文档或读取失败 | 在工作台显示具体状态与恢复办法；失败后可刷新重试 |
| FR-06 | 禁用或重新启用插件 | 注册资源随插件卸载；仅当本页正在显示时返回对话；重新启用可重新打开 |

## 4. 界面与交互

拟议线框如下，仅表示区域与操作关系：

```text
DSH 侧栏                  DSH 主区域
SDD 工作台                SDD 工作台       [刷新] [返回对话]
                          工作区 [会话/目录选择]
                          Feature [编号与标题选择]  Phase
                          [简报] [产品规格] [技术设计] [评审…]
                          文档路径
                          Markdown 正文（独立滚动）
```

使用 DSH 主题色和原生页面布局。宽度不足时控件换行；文档表格与代码块局部横向滚动。所有操作使用带名称的原生按钮/选择框，支持 Tab、Enter、Space。选中文档以 `aria-pressed` 表达。读取中显示忙碌状态，刷新按钮禁用，切换目标后旧请求不得覆盖新内容。

文案规则：入口“SDD 工作台”；动作“刷新”“返回对话”；无会话“请先在目标工作区创建一个会话”；无目录“此工作区尚未初始化 my-ai-infra，请在仓库根目录运行 mai init”；缺文档“此阶段文档尚未生成”；失败“读取失败，请刷新重试”。英文提供对应翻译，最终界面文案由插件 locale 字典维护。

## 5. 规则与边界

- 仅展示本地文件，不编辑、创建、删除或执行阶段命令；不新增模型调用，不需要 API key。
- 默认识别 my-ai-infra 标准目录；自定义 `FEATURE_LAYOUT.json` 的路径适配留待后续版本。界面明确提示使用标准目录。
- BRIEF 的 Phase 是文件中的声明；文件存在不代表评审通过或验收通过，不计算虚假完成率。
- 只读取选定 `mai-specs/NNN-slug` 下的固定文档路径。Markdown 原始 HTML 不执行，图片不自动加载，链接不自动读取本地其他文件。
- 读取受 DSH 现有权限与分页限制约束。超过一页时明确标注内容不完整并允许加载下一页，不能静默截断；目录截断也须提示。

## 6. 验收标准（唯一维护源）

| ID | Given / When | Then 与验证方法 |
|---|---|---|
| AC-01 | 插件安装启用，点击入口再点击返回 | 页面在 DSH 内打开并返回对话；实测浏览器，不以注册文件代替 |
| AC-02 | 工作区有两个标准 Feature，切换选择 | 仅列 Feature；标题、Phase、对应文档与实际磁盘一致；实测并核对样例 |
| AC-03 | 文档含标题、列表、代码和表格 | Markdown 正确显示；原始 HTML 不执行；开发测试及实际页面检查 |
| AC-04 | 当前文档在磁盘更新后点击刷新 | 新内容出现；快速切换时旧请求不串到新选择；开发测试及实际页面检查 |
| AC-05 | 缺根目录/缺文档/拒绝读取/长文档 | 有可恢复的明确状态；分页追加不冒充完整；针对性测试与可用的实际错误页面检查 |
| AC-06 | 禁用、启用插件并重新启动 DSH | 入口与页面随生命周期清理，启用和重启后可以再次打开；实际宿主验证 |

## 7. 范围说明

本次不包含文档编辑、阶段执行、自动监控、GitHub 发布或模型聊天。提交说明需提供依赖、启动、安装、验证入口及 SDD 文档索引。没有阻塞产品决策；宿主接口和安装行为需在实施中核验，未验证不能结项。
